# Motivation
Small repo with Dockerfile to build and run:
https://github.com/1CatAI/1Cat-vLLM
## build 
```
docker build -t 1cat-vllm:v1.5.1 .
```

# run NVFP4
```
docker run --gpus all --ipc=host -p 8000:8000 \
  -e PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
  -v /home/xix/Downloads/:/models \
  1cat-vllm:v1.5.1 \
  --model /models/Swift-1.5-Qwen3.8-27b-NVFP4 \
  --speculative-config '{"method": "draft_model", "model": "/models/Qwen3.8-27B-DFlash2", "num_speculative_tokens": 7}' \
  --kv-cache-dtype fp8_e4m3 \
  --gpu-memory-utilization 0.95 \
  --max-model-len 3072
```

# request 
```
curl http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "/models/Swift-1.5-Qwen3.8-27b-NVFP4",
    "messages": [
      {
        "role": "user",
        "content": "Write a single-file HTML page containing a Three.js voxel game similar to Minecraft.\nRequirements:\nUse THREE.InstancedMesh to render a 32x32 terrain grid with varying heights generated by a simple noise/math function.\nInclude a PointerLockControls first-person camera (WASD to move, mouse to look, Space to jump).\nImplement basic collision with the ground and simple gravity.\nAdd raycasting so left-clicking removes a block and right-clicking places a block.\nKeep all CSS, HTML, and JS inside one file without external build steps"
      }
    ],
    "max_tokens": 3500,

  }'
```
